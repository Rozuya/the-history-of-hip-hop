# THE HISTORY OF HIP-HOP

Première version du site documentaire consacré à l'histoire mondiale du hip-hop, de ses influences des années 1960 à 2026.

## Fonctionnalités actuelles
- Accueil cinématographique et identité visuelle vintage.
- Chronologie interactive par décennies et années.
- Filtre pays/région et recherche dans les événements.
- Premiers repères historiques avec liens vers des organismes de référence.
- Mise en page adaptée aux ordinateurs, tablettes et téléphones.

## Publier avec GitHub Pages
1. Ouvrir **Settings → Pages** dans le dépôt.
2. Sous **Build and deployment**, choisir **Deploy from a branch**.
3. Sélectionner la branche `main` et le dossier `/ (root)`, puis enregistrer.
4. Adresse attendue : https://rozuya.github.io/the-history-of-hip-hop/

## Administration sécurisée
L'interface d'administration et l'authentification ne sont pas encore configurées. Ne placez jamais de mot de passe ni de jeton GitHub dans les fichiers publics du site. Une solution d'authentification côté serveur devra être ajoutée avant d'activer la publication depuis l'administration.

## Images et droits
L'image d'accueil est une image distante de démonstration. Avant une publication éditoriale définitive, vérifier les licences, crédits et conditions de réutilisation des photographies et pochettes d'albums.

Les premières notices constituent un point de départ, pas une encyclopédie exhaustive. Elles doivent être progressivement enrichies et documentées.
